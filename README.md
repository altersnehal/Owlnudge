# 🦉 Owlnudge · ADHD Accountability & Gentle Recovery Mentor

> **Hackathon Checkpoint 1 Progress Deliverable**  
> An empathetic, slop-free AI coach designed specifically for neurodivergent learners. Optimizes for **momentum recovery after setbacks** rather than toxic streaks.

---

## 🎯 Problem Statement
Many ADHD learners struggle to complete long-term learning goals despite having high motivation and talent. Traditional habit and productivity apps fail because:
- **Initiation Paralysis:** The first 2 minutes of starting a task feel overwhelming.
- **Time Blindness & Hyperfocus:** Losing track of biological needs leading to afternoon burnout crashes.
- **The Shame Spiral:** Missing a day triggers guilt from broken streak counters, leading to app avoidance.

---

## 🌟 Unique Value Proposition: The Zero-Shame Buffer Engine
Most apps optimize for planning. Most habit apps optimize for tracking.  
**Owlnudge optimizes for momentum restoration after loss of momentum.**

1. **Auto-Injected Buffer Days:** Automatically reserves **2 Buffer Days per 7-day interval** to absorb life setbacks without delaying your target completion date.
2. **Sequential Dopamine Ladder:** Slices daunting tasks into 30-second micro-steps. Only 1 step is unlocked at a time.
3. **Procedural Neuro-Acoustic Synthesizer:** Real-time Brown Noise generator running locally via Web Audio API (0ms latency, 100% offline).
4. **Bounce-Back Velocity Metric:** Measures recovery resilience instead of punitive consecutive streaks.

## 🛠️ Tech Stack & Architecture

- **Frontend:** React 18 + Vite + Tailwind CSS
- **Audio Synthesis:** Native HTML5 Web Audio API (`AudioContext` procedural brown noise curve)
- **Design Intelligence:** `design-taste-frontend` + `emil-design-eng` + `ui-ux-pro-max` + `impeccable`
- **AI Engine:** Dual-adapter (Local Ollama bridge at `localhost:11434` with structured JSON + deterministic ADHD heuristic slicer fallback)
- **State & Storage:** LocalStorage + 1-click Markdown exporter (`roadmap.md`)

## 🚀 Local Quickstart

```bash
# Clone the repository
git clone https://github.com/altersnehal/Owlnudge.git
cd Owlnudge

# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:3000` to interact with the full live app.
