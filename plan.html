03 · Architectural Alignment & Consent

Key Decisions Requiring Your Consent Before Execution

1. Local AI Engine & Fallback Strategy

We will implement a pluggable adapter:
• Primary: Local Ollama (`http://localhost:11434` calling `llama3.2` / `mistral` with structured JSON mode).
• Fallback: Deterministic rule-based prompt simulator so that if Ollama is not started, the app never crashes during demo.

Recommended: Dual Adapter (Ollama + Zero-Fail Fallback)

2. Real-Time Web Audio vs Static Audio Files

We will generate brown noise and rain sounds purely in code using the browser's native `AudioContext` and noise mathematical curves.
• Zero external MP3 downloads or copyright issues.
• Instant offline performance and continuous uninterrupted loops.

Recommended: Native Web Audio Synthesis

3. Data Persistence (Local JSON + Markdown Export)

We will store user roadmap, check-in history, and buffer ledger in browser `localStorage` + offer instant 1-click export to a clean human-readable Markdown file (`roadmap.md`).

Recommended: LocalStorage + Markdown Exporter

4. React + Vite + Tailwind CSS Architecture

Zero-bloat, ultra-responsive Single Page Application running on standard Vite local port, fully modularized by component leaf architecture.

Recommended: React + Vite + Tailwind
